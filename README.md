# Pokémon Pals Adventure

Hola. Me gustaría diseñar un juego para niños de cuatro años. Este juego me gustaría que estuviera ambientado en el mundo Pokémon, ¿vale? Es decir, puede ser un juego por turnos, ¿no? En el que tú, pues, eh, vas adquiriendo conforme vas subiendo de nivel, vas desbloqueando, mmm, eh, Pokémon y, y luego, pues, mmm, vas luchando contra otros, ¿no? Imagínate que vas a luchar, ¿no? Y ya está. Algo muy sencillo, con botones grandes, eh, que apenas tenga texto y que sea todo muy llamativo.
